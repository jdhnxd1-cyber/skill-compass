# Skill Compass 🧭 — دليل النشر الحقيقي

المنصة دلوقتي بقت جاهزة تشتغل كموقع حقيقي على الإنترنت، مش بس جوه Claude. هي مبنية من 3 أجزاء:

1. **الفرونت إند** (`index.html`) — نفس واجهة الخريطة اللي شفتها، بس بقت بتكلم السيرفر بتاعك بدل ما تكلم أي AI مباشرة من المتصفح.
2. **الباك اند** (مجلد `api/`) — 3 دوال سيرفرلس (Vercel Functions) بتشتغل بالنيابة عنك:
   - `recommend.js`: بتاخد بيانات الطالب وتكلم **Gemini API** بمفتاحك الخاص (مخفي، مش ظاهر في المتصفح أبدًا)
   - `save-profile.js`: بتحفظ بيانات الطالب في قاعدة بيانات حقيقية (Supabase)
   - `load-profile.js`: بترجع بيانات الطالب لما يسجل دخول بإيميله
3. **قاعدة البيانات** — Supabase (مجانية للمشاريع الصغيرة).

---

## الخطوة 1: احصل على مفتاح Gemini API

1. روح على https://aistudio.google.com/apikey
2. اعمل تسجيل دخول بحساب Google، واضغط "Create API Key"
3. انسخ المفتاح واحفظه (هتحتاجه في خطوة 4)

> ملحوظة: راجع اسم الموديل الحالي في `api/recommend.js` (حاليًا مكتوب `gemini-2.5-flash`) — لو ظهر إصدار أحدث في AI Studio وقت ما تنشر، غيّره هناك.

---

## الخطوة 2: جهّز قاعدة البيانات (Supabase)

1. اعمل حساب مجاني على https://supabase.com
2. اعمل مشروع جديد (Project)
3. من قايمة **SQL Editor** جوه المشروع، شغّل الكود ده مرة واحدة بس:

```sql
create table students (
  email text primary key,
  payload jsonb not null,
  saved_at timestamptz default now()
);
```

4. من **Project Settings → API**، هتلاقي:
   - `Project URL` → ده الـ`SUPABASE_URL`
   - `service_role` key (تحت "Project API keys") → ده الـ`SUPABASE_SERVICE_ROLE_KEY`

⚠️ الـ `service_role` key ده قوي جدًا (بيقدر يعدّل كل حاجة في القاعدة). متحطهوش في الفرونت إند أبدًا — إحنا حاطينه في الباك اند بس (متغيرات بيئة Vercel)، وده صح ومطلوب كده بالظبط.

---

## الخطوة 3: ارفع المشروع على GitHub

1. اعمل حساب على https://github.com لو معندكش
2. اعمل Repository جديد (خاص أو عام، زي ما تحب)
3. ارفع الملفات كلها اللي في المجلد ده (`index.html`, `package.json`, `vercel.json`, `api/`)

---

## الخطوة 4: انشر على Vercel

1. اعمل حساب على https://vercel.com (تقدر تسجل بحساب GitHub بتاعك على طول)
2. اضغط **Add New → Project** واختار الـRepository اللي رفعته
3. قبل ما تضغط Deploy، افتح **Environment Variables** وضيف الـ3 دول:

| Key | Value |
|---|---|
| `GEMINI_API_KEY` | المفتاح من الخطوة 1 |
| `SUPABASE_URL` | من الخطوة 2 |
| `SUPABASE_SERVICE_ROLE_KEY` | من الخطوة 2 |

4. اضغط **Deploy**. خلال دقيقة أو اتنين هيديك رابط زي:
   `https://skill-compass-xxxx.vercel.app`

ده الرابط اللي تقدر تبعته لأي حد يستخدم المنصة فعليًا من أي مكان في الدنيا.

---

## الخطوة 5 (اختياري): دومين خاص بيك

من داخل المشروع في Vercel → **Settings → Domains**، تقدر تضيف دومين اشتريته (من Namecheap أو GoDaddy مثلًا) زي `skillcompass.com` بدل رابط Vercel الطويل.

---

## بعد النشر — إيه اللي المفروض يشتغل؟

- أي حد يفتح الرابط، يكمل الخطوات، ويجيله ترشيحات حقيقية من Gemini.
- بياناته بتتحفظ فعليًا في Supabase، وتقدر ترجعلها بالإيميل من أي جهاز.
- تقدر تتابع كل الطلبات والمستخدمين من **Vercel → Logs** (لمعرفة الاستخدام) و**Supabase → Table Editor → students** (لتشوف كل الطلاب اللي استخدموا المنصة).

## تكاليف متوقعة (البداية)

- **Vercel**: مجاني للمشاريع الصغيرة (Hobby plan)
- **Supabase**: مجاني لحد 500 ميجا بيانات و50 ألف مستخدم شهريًا
- **Gemini API**: فيه حصة مجانية شهرية، وبعدها الدفع بالاستخدام (رخيص جدًا للنص)

يعني تقدر تشغّل المنصة بالمجان تمامًا في الأول لحد ما يزيد عدد المستخدمين بشكل كبير.
